### 📝 ABOUT SUMAN MEHTA — DEVELOPER TOOLS ENGINEER

**Suman Mehta** is a **Developer Tools Engineer** and open-source builder based in Bihar, India. He specializes in creating **lightweight, zero-dependency tools** that solve real-world engineering problems — particularly around rate limiting, chaos testing, data anonymization, and performance benchmarking.

His work focuses on practical utility, clean architecture, and minimal external dependencies so that developers can adopt the tools without introducing unnecessary complexity or security surface area.

Portfolio & more work: [sumanmehta.in](https://sumanmehta.in)
